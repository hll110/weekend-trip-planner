# 渝趣周边游 · 新增路线指南

只需改 **一个文件** 即可增加/修改路线（无需改页面代码）。

## 第一步：编辑路线数据

打开文件（微信小程序**必须**用 `.js` 格式加载数据）：

```
miniprogram/data/routes.js
```

在 `module.exports = [ ... ]` 数组里**复制** `route-template.json` 中的对象，改字段后保存并重新编译。

> 若你更习惯改 JSON：可编辑 `routes.json`，再在项目根目录执行  
> `node scripts/sync-routes.js` 同步到 `routes.js`。

| 字段 | 说明 | 示例 |
|------|------|------|
| `id` | 唯一数字，不要与已有重复 | `13` |
| `name` | 路线名称 | `涪陵武陵山一日游` |
| `type` | `scenic` 景区 / `food` 美食 / `hiking` 徒步 | `scenic` |
| `duration` | `1day` 或 `2day` | `1day` |
| `district` | 区县 id，见 `extensions.js` 里 districts | `fuling` |
| `seasons` | 适合季节数组 | `["spring","autumn"]` |
| `images` | **多图路径数组**（见下文） | 见下方 |
| `spots` | 景点列表，含 lat/lng 可导航 | 模板内有示例 |

## 第二步：添加图片（多张）

**方式 A：脚本批量下载（推荐）**

1. 在 `miniprogram/data/route-image-sources.js` 中为该路线 id 填写图片 URL（可用 Unsplash 等可直链的免费图）
2. 运行：`node scripts/download-route-images.js`（图片会保存到 `miniprogram/images/routes/` 并自动更新 `routes.js`）
3. 重新编译小程序

**方式 B：手动放本地图**

1. 把照片放到 `miniprogram/images/routes/`，命名如 `13-1.jpg`
2. 在 `routes.js` 里写：
   ```json
   "images": ["/images/routes/13-1.jpg", "/images/routes/13-2.jpg"]
   ```

路线展示使用本地路径，**不需要**为图片配置外网合法域名。

## 第三步：重新编译

微信开发者工具点击 **编译**，首页和详情页会自动显示新路线及图片轮播。

---

## 可选：后端 API 模式

若 `miniprogram/config.js` 中 `enableRemoteApi: true`，也可在项目根目录维护：

```
routes_data.json
```

格式与 `routes.json` 相同，由 `server/app.py` 加载。
