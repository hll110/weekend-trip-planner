## 快速开始

### 本地运行

```bash
# 安装依赖
pip install -r requirements.txt

# 运行
python3 app.py
```

### Docker运行

```bash
# 构建镜像
docker build -t project-name .

# 运行容器
docker run -d -p 9090:9090 project-name
```

## 访问

- 本机: http://localhost:9090
- 局域网: http://你的IP:9090
